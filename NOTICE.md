# Provenance notice

Touhou PC-98 RL contains a substantially revised subset of the GPL-3.0-or-later
Rust memory-reading and TH05 reverse-engineering code from
[`touhourl/thrl`](https://github.com/touhourl/thrl), originally by T. Liu and
contributors. The Git history and source copyright notices are retained.

TH05 executable transformations are applied at runtime from
[`touhourl/th05patch`](https://github.com/touhourl/th05patch); the patches and
game executables are not redistributed here. DOSBox-X and ReC98 are independent
projects used for emulation and validation. Touhou game data is not included.
